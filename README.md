# Multi-Tenant Team Note-Taking Backend Service

A lightweight, high-performance RESTful API built with **ASP.NET Core** and **SQL Server**.

## 🛠️ Installation & Setup
1. Execute `Database/init.sql` inside your SQL Server instance.
2. Open `TeamNotesService.sln` using Visual Studio.
3. Verify connection details in `TeamNotesApi/appsettings.json`.
4. Hit **F5** to build and launch with Swagger interface.
